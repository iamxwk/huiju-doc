查询商品元数据

用于查询商品元数据。
权限说明需要获取 在用商品-读 权限
请求方式GET https://api.huiju.cool/v2/goods/meta?access_token={access_token}
请求示例
请求地址
GET https://api.huiju.cool/v2/goods/meta?access_token={access_token}
参数
必填
描述
access_token是接口调用凭证
返回示例
{
  "data": [
    {
      "name": "name",
      "label": "名称",
      "innerType": "String",
      "isSystemMeta": true
    },
    {
      "name": "c_test1",
      "attr": "attr31",
      "isSystemMeta": false,
      "innerType": "String",
      "label": "测试"
    }
  ]
}
参数
类型
描述
nameString属性标识
isSystemMetaBoolean是否系统属性
innerTypeString属性类型，有String，Date，DateTime，Integer，Long，Decimal
labelString属性名称
attrString属性对应的系统的自定义列名
